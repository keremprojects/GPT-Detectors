# 🧠 GPT Detectors: LLM vs Human Text Classification

This project investigates the ability of various models to distinguish between human-written and LLM-generated texts (e.g., ChatGPT). We analyze different model types, including zero-shot and fine-tuned classifiers, and compare their output probabilities and decision boundaries.

## 🗂️ Contents

- `GPT-detectors.ipynb`: Main analysis notebook
- Sample texts from both ChatGPT and human authors
- Model predictions, probability outputs, and visualizations

## 🧪 Key Features

- Analysis of GPT vs human text using various detectors
- Comparison of zero-shot vs fine-tuned classification models
- Visualization of output probabilities
- Case examples of misclassified texts

## 📊 Technologies Used

- Python
- Jupyter Notebook
- scikit-learn
- matplotlib / seaborn (for plots)
- Hugging Face Transformers (for LLMs)
